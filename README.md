\# ChemLab 🧪



\*\*ChemLab\*\* is a web-based Chemistry Laboratory Equipment Borrowing and Inventory System with Real-Time Monitoring developed for PHINMA Cagayan de Oro College – Carmen, Puerto, and Iligan Campuses.



\## Features



\- Equipment and Inventory Management

\- Equipment Borrowing and Returns

\- Borrowing Request Approval

\- Real-Time Equipment Monitoring

\- Equipment Maintenance Tracking

\- Reports and Notifications

\- Multi-Campus Management



\## Built With



\- Laravel 12

\- Vue 3

\- Inertia.js

\- TypeScript

\- Tailwind CSS

\- PostgreSQL

\- Docker



\## Purpose



To make laboratory equipment borrowing, inventory tracking, and monitoring easier, more organized, and efficient across multiple campuses.
